# JAVASCRIPT-PROJECTS
This repository contains the JavaScript projects and assignments I completed for my course. 
Each project helped me practice different JavaScript concepts, including variables, functions, loops, arrays, DOM manipulations, AJAX, jQuery, Bootstrap, and working with webpages. As I continue through the course, I will add more projects to this repository to show what I have learned and how my programming skills have improved over time.

##Projects
-Pizza Menu
-Calculator
-Tic-Tac-Toe Game
-AJAX Project

PIZZA MENU
This project is an interactive pizza ordering application . Users can select a pizza size and toppings, and JavaScript calculates the total price based on their selections.

Skills Used:
-JavaScript
-Functions
-Arrays
-DOM Manipulation
-HTML & CSS

CALCULATOR
This project is a basic four-function calculator. Users can add, subtract, multiply, and divide numbers using an interactive calculator interface.

Skills Used:
-JavaScript
-Functions
-Operators
-Event Handling
-HTML & CSS

TIC-TAC-TOE GAME
This project recreates the classic Tic-Tac-Toe game. The computer plays against the user, checks for winning combinations, and displays animations and sounds when the game ends.

Skills Used:
-JavaScript
-Arrays
-Game Logic
-DOM Manipulation
-HTML & CSS

AJAX PROJECTS
This project demonstrates how AJAX can load content into a webpage without refreshing the page. It retrieves a data from another file using JavaScript and displays it dynamically.

Skills Used:
-AJAX
-XMLHttpRequest
-JavaScript
-HTML & CSS
